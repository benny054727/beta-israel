# מדריך עדכון האתר

מדריך קצר למי שמנהל את האתר. לא צריך לדעת לתכנת.

## איפה מעדכנים מה

| מה רוצים לעדכן | איפה |
|---|---|
| טלפון, מייל, וואטסאפ, כתובת, זמני תפילות | `src/config.ts` |
| קישור לתרומה (נדרים פלוס או PayPal) | `src/config.ts`: השדות `donationUrl`, `paypalUrl` |
| פרטי אגודת אנדנט (מספר עמותה, סעיף 46) | `src/config.ts`: הקטע `association` |
| לוח אירועים | Google Calendar של בית הכנסת (אחרי שמזינים את המזהה ב-`googleCalendarId`) |
| טופס הזמנת סיור או צור קשר | Google Forms (אחרי שמזינים את הקישור ב-`tourFormUrl` / `contactFormUrl`) |
| מאמרי היסטוריה ותרבות | התיקייה `src/content/history` (קובץ `.md` לכל מאמר) |

## איך עורכים קובץ דרך GitHub (מהדפדפן)

1. נכנסים למאגר `benny054727/beta-israel` ב-GitHub.
2. פותחים את הקובץ ולוחצים על סמל העיפרון ✏️.
3. משנים את הטקסט **בין המירכאות** בלבד, לדוגמה: `phone: '02-1234567',`
4. לוחצים **Commit changes**.
5. אחרי 2–3 דקות האתר מתעדכן אוטומטית.

## הוספת מאמר חדש

יוצרים קובץ חדש בתיקייה `src/content/history`, למשל `05-food.md`:

```md
---
title: המטבח האתיופי
description: אינג'רה, דאבו, קפה ומסורת האירוח.
order: 5
icon: 🍲
reviewed: false
---

כאן כותבים את הטקסט. שורה ריקה מתחילה פסקה חדשה.

## כותרת משנה
```

אחרי שקייס או זקן קהילה אישר את המאמר, משנים את `reviewed: false` ל-`reviewed: true`, וההודעה "טיוטה" נעלמת.

## חיבור לוח האירועים (Google Calendar)

1. נכנסים ל-Google Calendar עם חשבון ה-Google של בית הכנסת ויוצרים יומן חדש בשם "אירועי בית הכנסת".
2. בהגדרות היומן מסמנים **"הפוך לזמין לציבור"**.
3. תחת **"שילוב היומן"** מעתיקים את **מזהה היומן** ומדביקים אותו ב-`googleCalendarId`.

## הגרסה האנגלית (/en/)

| מה רוצים לעדכן | איפה |
|---|---|
| דפי האנגלית | `src/pages/en/` (קובץ לכל דף, באותם שמות כמו בעברית) |
| מאמרים באנגלית | `src/content/history-en/`, באותו שם קובץ כמו המאמר בעברית |
| דף הבית (שתי השפות) | `src/components/HomePage.astro`: הטקסטים לכל שפה נמצאים בראש הקובץ |
| תפריט וכותרת תחתונה | `src/i18n.ts` |
| כתובת ושם האגודה באנגלית | `src/config.ts`: `addressEn`, `association.nameEn`, ובזמני תפילות `labelEn` |

**כשמוסיפים מאמר בעברית**, כדאי להוסיף גם את התרגום באנגלית באותו שם קובץ. אם אין תרגום, המאמר פשוט לא יופיע באנגלית.

## שמחות ואירועים בתשלום (/celebrations)

כל הפרטים של הדף נמצאים ב-`src/config.ts`, בקטע `celebrations`:

- **מחירים:** בכל אירוע משנים את המספר ב-`price`, וב-`extras` משנים את מחירי התוספות.
- **מחירים לדוגמה:** ⚠️ המחירים הנוכחיים הם לדוגמה. כשמכניסים את המחירים האמיתיים, משנים את `pricesAreExamples` ל-`false`, וההודעה "מחירים לדוגמה" נעלמת מהדף.
- **מספר אורחים:** כותבים ב-`capacity` כמה אורחים בית הכנסת יכול להכיל, למשל `'120'`.
- **הוספת אירוע:** מעתיקים בלוק של אירוע קיים ומשנים את הכותרת, הטקסט והמחיר, בעברית ובאנגלית.
- **טופס הזמנה:** מדביקים את הקישור לטופס Google ב-`celebrationFormUrl`.
